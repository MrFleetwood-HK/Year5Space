📖 Tech Words Bank

⚡ Core Concepts

Algorithm
Definition: A finite sequence of mathematically rigorous instructions to solve a problem.
In other words: A step-by-step list of rules or instructions to finish a job. An example is like following a pancake recipe!
Bug & Debugging
Definition: A bug is an error in software. Debugging is the process of fixing it.
In other words: A bug is a mistake in your code. Debugging means playing detective to find and fix it!
Loop
Definition: A programming structure that repeats a sequence of instructions.
In other words: Doing the same thing over and over again without having to write the code twice!
Variable
Definition: A symbolic name associated with a value that can be changed.
In other words: A labeled memory box inside a program that holds information. An example is like a box labeled "Score" that updates when you get a coin!

1843

👩‍💻 First Program

Ada Lovelace writes the world's very first computer algorithm for a mechanical computer.

1927

📺 Television Invented

Philo Farnsworth transmits the first electronic television picture.

1945

🖥️ First Giant Computer

The ENIAC is built. It was the first programmable general-purpose electronic digital computer, and it took up an entire room!

1947

🐞 First Recorded Bug

Grace Hopper finds a real moth trapped inside a computer and coins the term "debugging".

1950

🧠 AI Foundations

Alan Turing publishes a paper on computing machinery and intelligence, creating the famous "Turing Test".

1969

🌕 Moon Landing Code

Margaret Hamilton leads the software team. Her handwritten code safely lands Apollo 11 on the Moon!

1989

🌐 World Wide Web

Tim Berners-Lee invents the World Wide Web, creating the internet as we know it today using HTML.

2007

📱 iPhone Announced

Apple introduces the modern smartphone, putting powerful pocket computers in our hands.

2010

🖥️ iPad Released
