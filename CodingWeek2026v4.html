🌟 Coding Week 2026 Overview

Who Takes Part?

Everyone! Coding is for all ages and backgrounds:

• Kids like you: Learning how to build fun games, solve puzzles, and control computers!
• Complete Beginners: Grown-ups figuring out how apps work and learning a fun new skill.
• Tech Wizards: Coding experts who volunteer to teach us how to build amazing things.

Why Do We Code?

Coding is a superpower! When we learn to code, we:

• Build Confidence: See how a few lines of code can create something totally new!
• Solve Puzzles: We learn how to break huge challenges into tiny, easy steps (we call these algorithms!).
• Become Creators: Instead of just playing a game on your iPad, you learn the skills to build your very own game!

Awesome Future Jobs!

Did you know learning to code can lead to some of the coolest jobs in the world?

• Video Game Creator: Build your own 3D worlds, design characters, and write the physics rules for how high they can jump!
• Robot Trainer (AI): Teach computers how to learn, talk, and make decisions on their own.
• Space Data Scientist: Analyse massive patterns to help astronauts and space rovers explore the universe safely.
• Cyber Superhero: Protect important secrets and find hidden weaknesses before hackers can attack!

📖 Tech Words Bank

⚡ Core Concepts

🔢 Algorithm (al·guh·ri·thm)
Definition: A finite sequence of mathematically rigorous instructions to solve a problem.
🐞 Bug & Debugging (buhg & dee·buhg·ing)
Definition: A bug is an error in software. Debugging is the process of fixing it.
⚙️ Function (fuhnk·shun)
Definition: A reusable block of code that performs a specific, defined task.
📥 Input (in·poot)
Definition: Data or signals sent into a computer system (like typing on a keyboard or tapping a screen).
🧠 Logical Reasoning (loj·ih·kuhl ree·zuh·ning)
Definition: The process of using a rational, systematic series of steps to evaluate a problem or situation.
🔁 Loop (loop)
Definition: A programming structure that repeats a sequence of instructions.
📤 Output (out·poot)
Definition: Information or action produced by a computer system (like text on a screen or sound from a speaker).
🛤️ Sequencing (see·kwen·sing)
Definition: Putting instructions, events, or actions into the correct logical order.
📦 Variable (vair·ee·uh·buhl)
Definition: A symbolic name associated with a value that can be changed.

🛠️ Debugging Tips

Use this guide to find and fix errors in your code!

HTML vs CSS

• HTML is for adding content (Text, Images, Buttons, Links, Sections).
• CSS is for making it look pretty! (Colours, Backgrounds, Fonts, Size, Position).

🚨 Common Mistakes Checklist

• Did you check your Spelling? (Remember: Use American spelling like color instead of colour!)
• Are all your Brackets < > closed?
• Did you include both Start tags and End tags? (Don't forget the / in the end tag!)
• Did you spell src correctly for images? (Not scr!)
• Are your "quotation marks" and = signs in the right places?
• Do your Hex colour codes start with a #?
• Did you use colons : and semicolons ; correctly in your CSS?

📄 Common HTML Elements

• Headings: <h1> to <h6>. These are the only HTML elements that use numbers! (Use <h1> only once).
• Paragraphs: <p> for text. Don't forget the end tag </p>! Use <br/> for line breaks.
• Images: <img src="image.jpg"/>. This is a single tag.
• Links: <a href="www.example.com">. The end tag signals when the link stops.
• Lists: <ul> (unordered) or <ol> (ordered) containing <li> list items.
• Divisions: <div> used to group and organize your webpage!

🎨 Common CSS Properties

• color: Defines the text/border colour. (Selector must be specified first!)
• background-color: Defines the background colour.
• font-family: Changes fonts. Use quotes for specific fonts (e.g. "Impact").
• font-size: Uses units like px (pixels) or em.
• border: Needs 3 values: width, style, and color (e.g. 1px solid green).
• margin: Space between HTML elements.
• padding: Space inside an element.

⚙️ Common JavaScript Methods

• Number: Uses math operators (+, -, *, /).
• String: Stores text. Must be surrounded by quotation marks " ".
• Boolean: Binary! Can only be true or false.
• alert(); Triggers a pop-up message on the screen.
• prompt(); Triggers a pop-up with a text input field.
• confirm(); Triggers a pop-up with OK/Cancel buttons. Returns true or false.

Did you know? Most apps use multiple types of code at once! A website uses HTML for the words, CSS for the colours, and JavaScript to make buttons work.

🌐 JavaScript (JS) & HTML

What they build: The entire Internet! JavaScript is the programming language of the Web.

Why it matters: When you build web pages in BSD Online on your iPads, you are writing real HTML and JavaScript! HTML creates the building blocks (like images and paragraphs), while JavaScript adds the interactive logic (like making a game score go up).

🐍 Python

What it builds: NASA Space Rover navigation algorithms, advanced Artificial Intelligence (like ChatGPT), and massive data engines for companies like Spotify and Netflix.

Fact: It is named after the British comedy group Monty Python, not the snake! It is loved by programmers because its text is incredibly clean and easy to read.

📱 Swift

What it builds: Native apps specifically for iPad, iPhone, and Apple Watch.

Why it's awesome: Swift is incredibly fast and includes special tools built right in for programming Augmented Reality (AR) and 3D graphics on Apple devices.
